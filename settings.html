Vader Sentiment Analysis

VADER (Valence Aware Dictionary and sEntiment Reasoner) is a fast, lexicon and rule-based sentiment analysis tool specifically designed for social media and chat text.

It analyzes words, emojis, capitalization, and punctuation in a message to calculate a sentiment score from -1.0 (extremely negative) to 1.0 (extremely positive). If a chat message's score falls below your configured Negative Threshold (e.g., -0.5), it will be flagged as suspicious and sent to SAMMI.

Note: Vader sentiment analysis natively supports English only.
